# Ashley — Business × Data × AI Portfolio

A responsive personal portfolio built with React and Vite. No paid APIs.

## Run locally / in GitHub Codespaces

```bash
npm install
npm run dev
```

Open the forwarded port 5173.

## Build

```bash
npm run build
```

## Before publishing

- In `src/main.jsx`, replace each project's `demo: null` with its verified public Streamlit URL.
- Check and correct the three GitHub repository links (they are provisional).
- Add a real email address and a resume PDF link when ready.
- Edit the project narratives to reflect only your actual experience and implemented features.
- Deploy with Vercel: Framework Vite; Build `npm run build`; Output `dist`.

All portfolio project data is simulated. The projects were developed with AI-assisted coding.
